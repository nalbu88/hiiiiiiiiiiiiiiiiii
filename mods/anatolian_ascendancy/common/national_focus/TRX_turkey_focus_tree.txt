# Layout (absolute x columns):
#     1-18  Foreign policy: alignment, regional pacts, irredentism
#    23-44  Armed forces: army (23-31), air force (34-38), navy (40-44)
#    47-83  Politics: Socialist | Kemalist | Democratic | Ottoman | Turanist
#           with cross-links Kadro -> Village Soviets, Liberal Kemalism ->
#           Free Elections and the shared Turkish-Islamic Synthesis
#    87-119 Economy: finance & trade, industry, infrastructure, energy &
#           resources, defence industry, agriculture
#   122-132 Society & science, and the East (Kurdish concessions)
#
# Performance notes:
#  - Every trigger below is a cheap country/state check. The few
#    any_country checks only run while a focus is being looked at.
#  - Map-wide loops only happen once, inside completion rewards, and use
#    every_owned_state wherever possible.
