###########################################################################
# Anatolian Ascendancy - decisions
#
# Performance notes:
#  - Every decision is gated by "allowed = { original_tag = TUR }", which
#    the game evaluates once at start-up. No other country ever evaluates
#    any trigger in this file.
#  - State-targeted decisions use an explicit "targets" list or
#    "state_target = any_owned_state" instead of scanning the whole map.
#  - Random outcomes (the Bourse, wildcat drilling) are rolled once, when
#    the decision completes or expires.
###########################################################################
